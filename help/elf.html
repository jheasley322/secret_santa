Set up a circle and text the kids

← All help

What works today

You can set up a circle, add kids, text them their links, watch who has finished, draw the names, tell the kids who they drew, and re-shuffle if you need to.

1. Sign in

  1. Open the Secret Santa site and type your email.
  2. Tap Send me a sign-in link.
  3. Open your email on the same phone or computer and tap the link. You are in.

There is no password. Each time you come back, ask for a new link.

No email? Look in your spam folder and wait a minute. Then try again. Check that you typed your email right.

2. Start a circle

A circle is one gift swap. On the home page, fill in Start a new circle.

  • Circle name: for example, Ava's Crew.
  • Budget: whole dollars, like 20. Leave it empty if there is none.
  • Swap date: the day you swap gifts. Please add one. The kids' phone numbers are wiped a week after this day. With no date, they are not wiped.
  • Place: optional.

Tap Create circle. You can change these later with Edit details on the circle page.

3. Add the kids

On the circle page, find Add a kid. Type a first name and a mobile number, then tap Add.

  • Use a number that gets texts. Dashes and brackets are fine.
  • Two kids can't have the same first name. Add a last initial, like Sam B.
  • Wrong kid? Tap Remove next to the name. Their wish list is deleted too.

We only keep a first name and a phone number. The number is only for sending texts. The kids never see anyone's number.

4. Send the invites

Tap Send invites. Each kid gets a text with their own private link.

  • Kids who already got an invite are skipped, so tapping again does not text them twice.
  • A kid with no number is skipped. You will see a note about it.
  • Texts cost real money, and there is a limit on how many can ever be sent. If you see a message about a text limit, ask the person who set up this app for you.

Next to each name you will see one of these:

  • Not sent yet: no text has gone out.
  • Text sent: the text went out.
  • Text sent (practice run): the app only pretended. Nothing reached the phone. This is how testing works.
  • Text failed: the text did not go out. The reason is shown under the name.
  • No number: there is no phone number to text.

5. Watch the checklist

At the top you will see something like 6 of 8 done. A check mark means that kid has finished their wish list. A cross means not yet.

Nudge the kids with a cross. If they lost the text, use Re-send or Copy link below.

6. Draw the names

When every kid has a check mark, tap Draw names. You need at least 3 kids. If the button is grey, the note under it says who you are waiting for.

  • Nobody is told yet. The draw is only on your screen.
  • Want to peek? Turn on Show matches. It spoils the surprise for you, so only do it if you need to.
  • Not happy with it? Tap Shuffle again as often as you like. It is free.
  • Undo draw goes back to before the draw.
  • To keep two kids apart, like brothers and sisters, add them under the never-pair list before you draw.

7. Send the names

Tap Send the names. Each kid gets a text, and their link now shows who they drew. Next to each name you can see if they have opened it.

After this, you cannot add or remove kids. If you need to change the draw, see the next part.

Changing the names after you sent them

Sometimes you need a new draw after the names went out. Tap Re-shuffle and text everyone.

  1. The first box explains what will happen. Tap Next, or Cancel to stop.
  2. The second box tells you how many kids will get a text. Tap Re-shuffle and text everyone to go ahead, or Cancel.

Cancel at either step and nothing changes.

  • Everyone gets one new text with their new name. Their link stays the same.
  • Nobody gets the person they had before. (They might still get someone who had them. That is fine.) Your never-pair list still counts.
  • It costs one text for every kid, the same as sending the names did. Texts are limited, so only do it when you must.
  • "Opened" starts over, so you can see who has looked at the new name.
  • You can do this about twice in the first hour. Each kid can only get 3 texts an hour, and the first names text already counts as one. If any kid is at the limit, nothing happens at all. Wait an hour and try again.
  • If it says it can't make a new draw, remove a never-pair and try again. Nothing was changed or sent.
  • A kid with no number still gets a new name, but cannot be texted. Tap Copy link and send it to them yourself. Their old name no longer counts.

If a kid's text fails, they still have the new name on their link. Tap Re-send next to their name, or Copy link.

A text did not arrive

Start with these steps, in order.

  1. Check the number next to the kid's name. Is it right? If not, tap Remove, then add them again with the right number.
  2. Tap Re-send next to their name. It sends the same link again. You can do this 3 times an hour for each kid.
  3. Still nothing? Tap Copy link, then paste the link into your own message to them.

The link is private. Only send it to that one kid.

Something else went wrong?

  • Reload the page and try again.
  • Circle not found: the circle belongs to a different Elf, or the web address is wrong. Go back to My circles.
  • Still stuck? Ask the person who set up this app for you.
