## Repo Summary

A tiny Secret Santa web app for a group of kids. An adult Elf creates a Circle, adds kids by first name and mobile number, and the app texts each kid a private link to fill in a wish list. When every list is done the Elf draws names in the database and the app texts every kid who they drew. Wish lists are public within the circle; matches are private to the giver and the Elf.

**Tech Stack:** Static HTML + ES modules + CSS (no build step), supabase-js (pinned CDN), Supabase Postgres + RLS + SECURITY DEFINER RPCs, Supabase Auth (email magic link, Elf only), Supabase Edge Function (Deno) for SMS, Textbelt SMS API, pg_cron, pgTAP, Vitest, Playwright, GitHub Pages / Netlify

## Project Rules (all agents)

1. **The spec is authoritative.** `.zReference/original_specs.md` beats existing code.

2. **Super simple.** When two designs both work, pick the one with fewer screens, fields and

3. **No build step.** Static HTML, ES modules, one stylesheet, and `supabase-js` from a pinned
   CDN version.
4. **The database is the only security boundary.** Members (kids) have no accounts. Their
   personal link token is their only credential, and they reach data only through SECURITY
   DEFINER RPCs. `anon` gets no table access.
5. **The secret stays secret.** A member sees only their own match, and only once the circle is
   `sent`. Only the Elf sees all matches.
6. **Kids' data is minimal:** a first name and a phone number. Phone numbers are never shown to
   members and are erased 7 days after the swap date.
7. **Escape everything rendered.** Prefer `textContent`.
8. **Never commit, print or set secrets.** `TEXTBELT_KEY` and the service-role key are Joe's to
   set. `.gitignore` covers `.env*`.
9. **HARD LIMIT on texts (Joe's orders).** The Textbelt balance is **749 credits** (2026-10-24, as Textbelt reported it), with the cap set to 745 to keep 5 in reserve. Only Joe changes it.
   - **No agent ever sends a real text.** Tests and development use `TEXTS_DRY_RUN=true`, and
     a missing value means dry run.
   - **No real text containing a link** may be sent until Joe says the Textbelt URL whitelist
     is approved (`TEXT_LINKS_APPROVED`, default false).
   - The Edge Function enforces a lifetime cap. See spec "Texting → HARD LIMITS".
   - The real key is in the local `.env` as `TEXTBELT_API_KEY` (Joe's copy). **No agent,
     script or test may read, load, print or use it.** Tests must not load `.env` in any way
     that exposes it to texting code. The Edge Function reads its own `TEXTBELT_KEY` from
     Supabase secrets, which Joe sets.
10. **Test-first.** test-author writes tests from the spec before implementation, and qa-gate
    must PASS before a phase is done.
